# Операционные руководства

> Тип: указатель. Запуск сервиса, управление доступом, моделями и базой данных.

Выберите нужную задачу ниже. Каждое руководство содержит команды, порядок
действий и признаки успешного результата.

Устройство сервиса описано в [архитектуре](../architecture.md), точные форматы
API — в спецификациях `app/contracts/`, причины решений — в
[журнале ADR](../adr/index.md). Каждая процедура описывается в одном основном
руководстве; справочник команд и инструкции установки ссылаются на него.

## Управление ресурсами

| Ресурс | Руководство | Операции |
| --- | --- | --- |
| Токены доступа | [Управление токенами](api-access-tokens.md) | Выпуск, просмотр, передача, замена и отзыв |
| База данных | [Миграции PostgreSQL](database-migrations.md) | Проверка версии, применение миграций и условия отката |
| Обученные модели | [Управление моделями](published-models.md) | Просмотр, удаление и отслеживание `DELETING` и `DELETED` |

## Запуск и эксплуатация

- [Эксплуатация сервиса](flight-service.md): требования, хранение данных,
  запуск, остановка, восстановление и диагностика.
- [Развёртывание через systemd](../deployment/systemd.md): проверенная процедура
  ручной установки на Fedora.
- [Настройка OpenSearch](../deployment/opensearch.md): индексы, доставка метрик
  и проверка отчётов.

Краткое начало работы находится отдельно в
[`getting-started.md`](../getting-started.md), а команды и их параметры
показывает `transformer <command> --help`.
