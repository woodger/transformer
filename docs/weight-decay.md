# weight_decay — это параметр L2-регуляризации

Вот как примерно воспринимаются значения `weight_decay`:

| Значение        | Как считается                  |
| --------------- | ------------------------------ |
| `0`             | Без L2-регуляризации           |
| `1e-6` — `1e-5` | Очень слабо                    |
| `1e-4`          | Стандартно, часто используется |
| `1e-3`          | Умеренно сильно                |
| `1e-2` и выше   | Уже агрессивно                 |

Так что:

`weight_decay = 1e-4` — нормальный, распространённый выбор.

Если "почти не трогать веса" - ставят `1e-5` или `1e-6`.
Если нужно активно прижимать веса к нулю - тогда уже `1e-3` или выше.
