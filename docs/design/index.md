# Проектные предложения

> Тип: указатель. Ненормативные Design Notes, находящиеся на активном
> архитектурном обсуждении.

Design Note исследует проблему, границы ответственности и реалистичные
варианты до принятия решения. Он не описывает текущее состояние, не изменяет
contract и не заменяет ADR.

После завершения обсуждения Design Note удаляется из текущей документации.
Принятое долгосрочное решение при необходимости получает ADR, а реализованное
состояние — изменения в профильных contracts и living documentation. История
самого предложения остаётся в Git.

## Активные предложения

- [Input Snapshot v1](input-snapshot-v1.md) — явное сохранение неизменяемого
  набора входных данных fit для повторного обучения без повторной
  материализации пакетов.
- [Target Head Diagnostics v1](target-head-diagnostics-v1.md) — отдельная
  проекция в области владельца со скалярными наблюдениями target head после
  epoch для контролируемых проверок переобучения.
